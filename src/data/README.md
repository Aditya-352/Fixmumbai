# Static Datasets

This directory contains static, read-only JSON data used for geospatial boundaries and localized lookup for the city of Mumbai.

## Files

- **`mumbai-wards.json`**: Geospatial definitions for Mumbai's municipal wards. Used to categorize civic issues into their respective local administration zones.
- **`mumbai-acs.json`**: Assembly Constituencies (AC) boundaries for Mumbai.
- **`mumbai-pcs.json`**: Parliamentary Constituencies (PC) boundaries for Mumbai.
- **`mumbai-places.json`**: A list of prominent places and landmarks in Mumbai to facilitate better search and issue localization.
