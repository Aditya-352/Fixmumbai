# React Components

This directory houses the reusable UI and feature-specific React components for the FixMumbai application.

## Structure

- **`home/`**: Components specific to the landing or homepage view.
- **`map/`**: Geospatial and mapping components, built around Leaflet and React-Leaflet (e.g., `MumbaiMap.tsx`).
- **`navigation/`**: Global navigation elements such as the Header and Footer.
- **`report/`**: The user-facing civic issue reporting flow (e.g., `ReportingWizard.tsx`).
- **`ui/`**: Reusable generic user interface elements (badges, sliders, form inputs).
- **`verification/`**: Components handling the community verification of civic reports.
